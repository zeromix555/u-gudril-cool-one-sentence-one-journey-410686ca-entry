# One Sentence, One Journey

A complete story about a journey, told in exactly one sentence, built for the
make.fun competition
[One Sentence, One Journey](https://make.fun/bounty/u-gudril-cool-one-sentence-one-journey-410686ca).

## The story

At dawn Mara leaves the grey harbour with her grandmother's brass compass and
a ticket she cannot read, walks three borders on foot when the train dies in
the snow, and comes home to find the kettle still warm and her own name
already written in the guest book — departure, obstacle, and an arrival that
changes what home means, all in a single breath.

## Run

```sh
node main.ts   # writes /output/entry.txt (UTF-8, 261 characters, one sentence)
```

`main.ts` uses only the Node standard library and writes the same bytes on
every run.
